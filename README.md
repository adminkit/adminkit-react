## Preview

A professional admin and dashboard template built with React, TypeScript, Vite and Bootstrap 5, with a dashboard, pages, forms, tables, charts and icons. Free and [MIT-licensed](LICENSE). [Open the demo](https://react-demo.adminkit.io/).

## Features

- **React and Vite:** React 19, strict TypeScript and React Router, built into static files you can host anywhere.
- **No Bootstrap JavaScript:** dropdowns, modals, alerts and the sidebar sheet are React components on Bootstrap's markup and classes.
- **Dark mode:** light, dark and auto, built on Bootstrap's color modes, without a flash on load.
- **Accessible:** targets WCAG 2.2 AA in light and dark mode.
- **Fully responsive:** the sidebar turns into an off-canvas sheet on small screens.
- **Modern tooling:** Sass, ESLint, Prettier and Playwright tests that check every page with axe.

## Quick start

Clone the repository and install the dependencies (Node.js 24):

```sh
git clone https://github.com/adminkit/adminkit-react.git
cd adminkit-react
npm install
```

Start the development server on http://localhost:5173:

```sh
npm run dev
```

Build the app into `dist/`, and preview it with `npm run preview`:

```sh
npm run build
```
